## 🎉 Novidades

A versão v1.2.0 adiciona **4 novos packages** focados em comunicação multi-canal, permitindo que suas aplicações Laravel enviem mensagens via **SMS** e **WhatsApp** de forma simples e confiável.

### 📦 Novos Packages

#### SMS Packages

##### 1. eduardoks98/sms-twilio
Integração oficial com Twilio para envio de SMS globalmente.

**Features**:
- ✅ SDK oficial Twilio (`twilio/sdk ^8.0`)
- ✅ Envio de SMS global (formato E.164)
- ✅ Templates com variáveis
- ✅ Envio em lote (bulk SMS)
- ✅ Webhooks para status de entrega
- ✅ Tracking completo em banco de dados
- ✅ Logs detalhados

**Arquivos**: 10 (Service, Enums, Models, Controllers, Migrations, Config, README)

**Uso Básico**:
```php
use Eduardoks98\SmsTwilio\Services\TwilioService;

$twilio = new TwilioService();

// Enviar SMS
$message = $twilio->send(
    to: '+5511987654321',
    body: 'Seu código de verificação é: 123456'
);

// Enviar com template
$message = $twilio->sendTemplate(
    to: '+5511987654321',
    template: 'verification_code',
    variables: ['code' => '123456']
);
```

##### 2. eduardoks98/sms-comtele
Provedor brasileiro de SMS com preços competitivos.

**Features**:
- ✅ API HTTP oficial Comtele
- ✅ Formato DDD+Number (brasileiro)
- ✅ Bulk SMS (até 100 destinatários)
- ✅ Templates com variáveis
- ✅ API de relatórios detalhados
- ✅ Rate limiting (cooldown de 30s)
- ✅ Tracking em banco de dados

**Arquivos**: 9 (Service, Enums, Models, Migrations, Config, README)

**Uso Básico**:
```php
use Eduardoks98\SmsComtele\Services\ComteleService;

$comtele = new ComteleService();

// Enviar SMS (aceita DDD sem código do país)
$message = $comtele->send(
    receivers: '11987654321',
    content: 'Seu código é: 123456'
);

// Enviar para múltiplos destinatários
$messages = $comtele->sendBulk(
    receivers: ['11987654321', '21987654321'],
    content: 'Promoção imperdível!'
);
```

#### WhatsApp Packages

##### 3. eduardoks98/whatsapp-official
Integração oficial com WhatsApp Business Cloud API (Meta).

**Features**:
- ✅ SDK oficial (`netflie/whatsapp-cloud-api ^3.0`)
- ✅ Mensagens de texto com preview de URL
- ✅ Mensagens de mídia (imagem, vídeo, áudio, documento)
- ✅ Templates pré-aprovados pelo WhatsApp
- ✅ Webhooks para atualizações de status
- ✅ Tracking completo em banco de dados
- ✅ Formato E.164 de telefone

**Arquivos**: 10 (Service, Enums, Models, Controllers, Migrations, Config, README)

**Uso Básico**:
```php
use Eduardoks98\WhatsAppOfficial\Services\WhatsAppService;

$whatsapp = new WhatsAppService();

// Enviar texto
$message = $whatsapp->sendText(
    to: '+5511987654321',
    text: 'Olá! Seu pedido foi confirmado.',
    previewUrl: true
);

// Enviar imagem
$message = $whatsapp->sendImage(
    to: '+5511987654321',
    imageUrl: 'https://example.com/image.jpg',
    caption: 'Confira nosso novo produto!'
);

// Enviar template
$message = $whatsapp->sendTemplate(
    to: '+5511987654321',
    templateName: 'order_confirmation',
    language: 'pt_BR',
    parameters: ['João', '12345', 'R$ 149,90']
);
```

##### 4. eduardoks98/whatsapp-converx
Provedor brasileiro de WhatsApp baseado em Chatwoot.

**Features**:
- ✅ API Converx (Chatwoot-based)
- ✅ Mensagens de texto
- ✅ Templates com parâmetros
- ✅ Gerenciamento automático de conversas
- ✅ Busca e criação automática de contatos
- ✅ Formato brasileiro (55XXXXXXXXXXX)
- ✅ Easy setup

**Arquivos**: 5 (Service, ServiceProvider, Config, README)

**Uso Básico**:
```php
use Eduardoks98\WhatsAppConverx\Services\ConverxService;

$converx = new ConverxService();

// Enviar mensagem (cria conversa automaticamente)
$response = $converx->sendMessage(
    phoneNumber: '11987654321',
    message: 'Olá! Como podemos ajudar?'
);

// Enviar template
$response = $converx->sendTemplate(
    phoneNumber: '11987654321',
    templateName: 'order_confirmation',
    parameters: [
        '1' => 'João Silva',
        '2' => '12345',
        '3' => 'R$ 149,90'
    ]
);
```

## 🔧 Configuração

### Variáveis de Ambiente

```env
# Twilio SMS
TWILIO_ACCOUNT_SID=your_account_sid
TWILIO_AUTH_TOKEN=your_auth_token
TWILIO_FROM_NUMBER=+1234567890

# Comtele SMS
COMTELE_API_KEY=your_api_key
COMTELE_API_URL=https://sms.comtele.com.br/api/v2

# WhatsApp Official (Meta Cloud API)
WHATSAPP_FROM_PHONE_NUMBER_ID=your_phone_id
WHATSAPP_ACCESS_TOKEN=your_access_token
WHATSAPP_WEBHOOK_VERIFY_TOKEN=your_verify_token

# WhatsApp Converx
CONVERX_ACCOUNT_ID=8
CONVERX_API_TOKEN=your_api_token
CONVERX_API_URL=https://converx.app/api/v1
CONVERX_INBOX_ID=1
```

### Publicar Configs e Migrations

```bash
# Publicar configs
php artisan vendor:publish --provider="Eduardoks98\SmsTwilio\SmsTwilioServiceProvider" --tag="config"
php artisan vendor:publish --provider="Eduardoks98\SmsComtele\SmsComteleServiceProvider" --tag="config"
php artisan vendor:publish --provider="Eduardoks98\WhatsAppOfficial\WhatsAppOfficialServiceProvider" --tag="config"
php artisan vendor:publish --provider="Eduardoks98\WhatsAppConverx\WhatsAppConverxServiceProvider" --tag="config"

# Publicar migrations
php artisan vendor:publish --provider="Eduardoks98\SmsTwilio\SmsTwilioServiceProvider" --tag="migrations"
php artisan vendor:publish --provider="Eduardoks98\SmsComtele\SmsComteleServiceProvider" --tag="migrations"
```

## 📝 Use Cases

### 1. Notificação de Pedido (Multi-canal)

```php
// Enviar por SMS (Brasil)
$comtele->send(
    '11987654321',
    "Pedido #{$order->id} confirmado! Total: R$ {$order->total}"
);

// Enviar por WhatsApp (global)
$whatsapp->sendTemplate(
    '+5511987654321',
    'order_confirmation',
    'pt_BR',
    [$order->customer_name, $order->id, $order->total]
);
```

### 2. Código de Verificação (2FA)

```php
// SMS via Twilio (global)
$code = rand(100000, 999999);
$twilio->sendTemplate(
    $user->phone,
    'verification_code',
    ['code' => $code]
);

// Armazenar código
Cache::put("verify:{$user->id}", $code, now()->addMinutes(5));
```

### 3. Notificação de Vendedor (Lead)

```php
// WhatsApp via Converx
foreach ($salesTeam as $seller) {
    $converx->sendTemplate(
        $seller->phone,
        'new_lead_notification',
        [
            '1' => $lead->name,
            '2' => $lead->phone,
            '3' => $lead->interest
        ]
    );
}
```

### 4. Campanha de Marketing (Bulk)

```php
// SMS em massa (Brasil)
$phones = Customer::active()->pluck('phone')->toArray();

$comtele->sendBulk(
    $phones,
    "🔥 Promoção! 50% OFF em todos os produtos. Válido até hoje!"
);
```

## 🔄 Webhooks

### Twilio SMS Webhook

```php
// routes/api.php
Route::post('/webhooks/twilio', [TwilioWebhookController::class, 'handleStatus']);

// Configura no Twilio Dashboard:
// Status Callback URL: https://yourapp.com/api/webhooks/twilio
```

### WhatsApp Official Webhook

```php
// routes/api.php (já registrado pelo package)
Route::get('/api/webhooks/whatsapp', [WhatsAppWebhookController::class, 'verify']);
Route::post('/api/webhooks/whatsapp', [WhatsAppWebhookController::class, 'handleWebhook']);

// Configura no Meta Dashboard:
// Callback URL: https://yourapp.com/api/webhooks/whatsapp
// Verify Token: (definido em WHATSAPP_WEBHOOK_VERIFY_TOKEN)
```
