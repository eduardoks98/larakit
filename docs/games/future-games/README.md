- PvP competitivo
- Sistema D&D
- Socket.IO multiplayer

### 2. Party Games (Próximo)
- Quiz multiplayer
- Drawing games
- Reutiliza SDK do Buckshot
- Desenvolvimento rápido

### 3. Deck Builder ou TD
- Mais complexo
- Após estabilizar Arena

### 4. Auto Battler
- Maior complexidade
- Longo prazo
